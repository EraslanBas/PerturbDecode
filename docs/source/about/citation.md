# Citing PerturbDecode

## The method and the screen

throughout this documentation. If you use the package or the data, please cite:

> Geiger-Schuller K\*, Eraslan B\*, Kuksenko O, Dey KK, Jagadeesh KA, Thakore PI,
> Karayel O, Yung AR, Rajagopalan A, Meireles AM, Yang KD, Amir-Zilberstein L,

> Doench JG, Uhler C, Rozenblatt-Rosen O, Regev A.

> inflammatory responses with massively parallel Perturb-seq.**

## Data availability

The screen is deposited at
[GEO GSE327057](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE327057),
with raw reads under BioProject
[PRJNA1449386](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1449386).

## Code availability

- **PerturbDecode**, this package:
  [github.com/EraslanBas/PerturbDecode](https://github.com/EraslanBas/PerturbDecode)
- **PerturbDecode_v1**, the analysis code used for the manuscript:
  [github.com/EraslanBas/PerturbDecode_v1](https://github.com/EraslanBas/PerturbDecode_v1).
